# AI会社 ダッシュボード（見る専用）

AI会社の記録を、スマホで一目で確認するための画面です。

- 表示するだけで、書き換え・実行・設定変更の機能はありません。
- ログインしたボスだけが読めます（データベース側で「読むだけ」の許可を、登録したユーザーにだけ与えています）。
- このリポジトリには、公開してよい設定（プロジェクトのURLと公開用の鍵）しか入っていません。
- 表示にAIは使わないので、開いても費用はかかりません。

## 更新するとき
`app.js` などを変えたら、`index.html` の `?v=` の数字も変える（スマホに古いファイルが残って、画面が混ざるのを防ぐため）。
